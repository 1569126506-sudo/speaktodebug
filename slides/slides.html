The problem

  • Bugs strike while your hands are busy — mid-edit, mid-review, second screen
  • Chat assistants can talk about code, but they have never seen your code
  • Pasting context, copying errors, switching windows — every step breaks flow
  • Voice is how you'd explain it to a colleague. So why not to your tools?

Real tools, real code

  • search_code — recursive grep across your actual project
  • read_file — opens the suspicious lines, line-ranged
  • run_tests — executes your real test suite (npm test)
  • list_files — maps the project tree
  • Sandboxed: every path is jailed to the workspace; 15-check self-test

Deep AssemblyAI integration

  • One WebSocket handles STT + reasoning + voice output + turn-taking
  • Interactive tool.call / tool.result loop — the core of the demo
  • Session schema tuned: jitter buffer, min_latency for real-time answers
  • Chinese-first: STT keyword biasing + zh-CN voice output, bilingual captions
